# Lecture-Hunter 크롬 확장

유튜브 같은 강의 페이지 위에 Lecture-Hunter 위젯을 띄우고, 그 탭의 소리를 로컬 백엔드로 보내 실시간 자막을 만듭니다.

## 준비

세 가지가 켜져 있어야 합니다 (명령은 루트 README의 STEP 4).

| 무엇 | 주소 |
|---|---|
| Ollama | `ollama serve` |
| 백엔드 (FastAPI) | `http://127.0.0.1:8000` |
| 위젯 서버 (Flutter) | `http://127.0.0.1:9998` |

주소를 바꾸려면 `config.js`만 고치면 됩니다.

## 설치

1. `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 `Extension/` 폴더 선택
3. 퍼즐 아이콘에서 Lecture-Hunter를 고정

코드를 고친 뒤에는 `chrome://extensions`에서 새로고침(↻)을 누르고, 열려 있던 탭도 새로고침하세요.

## 사용

| 하는 일 | 방법 |
|---|---|
| 강의 시작 | 강의 탭에서 아이콘 클릭 → 오른쪽 위에 위젯, 배지 `ON` |
| 강의 종료 | 같은 탭에서 아이콘 한 번 더 클릭 (서버가 전체 요약을 저장) |
| 위젯 옮기기 | 로고·제목 줄을 드래그. 더블클릭하면 오른쪽 위로 돌아감. 위치는 기억됨 |
| 최소화 | 헤더의 `−` / 펼치기는 `펼치기 +` |
| 화면 질문 | 질문 탭 → AI에게 질문 → **화면 캡처**. 위젯을 잠깐 숨기고 지금 보이는 탭 화면을 찍어 첨부 |
| 전체화면 | 유튜브 전체화면에서도 위젯이 영상 위에 보임 |

- 강의 ID는 `yt-<영상ID>-<날짜-시각>` (유튜브) 또는 `tab-<날짜-시각>` (다른 사이트)로 매번 새로 만들고, 탭 제목을 강의 제목으로 저장합니다.
- 한 번에 한 탭만 강의로 잡습니다. 다른 탭에서 아이콘을 누르면 앞의 강의를 끝내고 새로 시작합니다.
- 탭 소리를 캡처하면 크롬이 원래 소리를 끄기 때문에, 확장이 같은 소리를 다시 재생합니다 (원래 음질 그대로).
- 유튜브는 새로고침해도 위젯이 다시 뜹니다. 다른 사이트에서 페이지를 옮기면 위젯이 사라지는데, 아이콘을 누르면 다시 뜹니다 (오디오는 계속 전송 중).

## 배지

| 배지 | 뜻 |
|---|---|
| `…` (주황) | 백엔드에 연결 중 / 다시 연결 중 |
| `ON` (초록) | 탭 오디오 전송 중 |
| `!` (빨강) | 오류. 아이콘에 마우스를 올리면 이유가 보임 |

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "위젯을 불러오지 못했어요" 카드 | 위젯 서버(9998)가 꺼져 있음. 켠 뒤 **다시 불러오기** |
| 자막 탭에 "오디오 재연결 중" | 백엔드(8000)가 꺼져 있음. 켜면 1~10초 안에 자동으로 다시 붙고, 끊긴 동안의 소리도 최근 10초까지 보냄 |
| 자막이 늦게 나옴 | `WHISPER_MODEL_SIZE=medium`은 M1에서 10초 이상 늦음. 번역까지 보려면 `small` |
| `chrome://`, 웹스토어에서 `!` | 크롬이 확장을 막는 페이지. 일반 웹페이지에서 사용 |
| 화면 캡처가 공유 창으로 열림 | 확장 캡처가 실패하면(페이지 이동 직후 등) 화면 공유 → 이미지 파일 순서로 대신함 |

## 구조

```text
아이콘 클릭
  └ background.js ── tabCapture streamId ──▶ offscreen.html/js ── 16kHz PCM ──▶ ws://127.0.0.1:8000/ws/audio/{id}?title=
        │                                       (pcm-worklet.js, 15초 ping, 자동 재연결)
        └ content.js (페이지) ─ 닫힌 shadow DOM + popover
              └ frame.html (확장 페이지) ── iframe ──▶ http://127.0.0.1:9998/?lecture_id={id}  (Flutter 위젯)
```

**위젯을 확장 페이지(frame.html) 안에 넣는 이유**: 크롬 142부터 Local Network Access 규칙 때문에 공개 사이트(youtube.com)가 `127.0.0.1`을 iframe으로 바로 열면 막힙니다. 확장 페이지는 `host_permissions`에 127.0.0.1이 있어 이 제한을 받지 않습니다.

**메시지** (`postMessage`, 출처·보낸 창을 확인)

| 방향 | type | 내용 |
|---|---|---|
| 위젯 → 확장 | `llai-ready` | 위젯 준비됨 |
| 위젯 → 확장 | `llai-layout` | `width`, `height`, `minimized`, `dragHandle {x,y,width,height}` |
| 위젯 → 확장 | `llai-capture-request` | `id` |
| 확장 → 위젯 | `llai-host` | 확장 안에서 실행 중, 지원 기능 |
| 확장 → 위젯 | `llai-audio` | `state` (connecting / connected / reconnecting / error), `message` |
| 확장 → 위젯 | `llai-capture-result` | `id`, `dataUrl` 또는 `error` |
